# ⚠️ Windows 用户必读：请使用绝对路径

由于 Windows 系统下工作目录（`user.dir`）可能随启动方式变化（如服务、快捷方式、脚本），**强烈建议 Windows 用户使用绝对路径**指定 `cacheDir`，以避免缓存目录位置不确定或权限问题。

---

# BiliMusicApi 配置文件说明

本插件通过 `bili.json` 进行配置，文件位于 AllMusic 数据目录（即 `plugins/AllMusic/` 或 `AllMusic/` 文件夹）下。首次启动时会自动生成默认配置，但 **`cacheDir` 和 `serveUrl` 为必填项**，需手动填写后方可启用 API。

---

## 📄 配置文件示例（Windows 推荐写法）

```json
{
  "cacheDir": "C:/music_cache",
  "serveUrl": "http://localhost:8090/",
  "ffmpegPath": "ffmpeg",
  "maxAudioLength": 45,
  "maxCacheSize": 100,
  "quality": 6,
  "advanced": {
    "maxRetry": 3,
    "retryDelay": 1500,
    "userAgent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36"
  }
}
```

> **Windows 路径注意事项**：
> - 推荐使用正斜杠 `/`（如 `C:/music_cache`），JSON 中无需额外转义。
> - 若使用反斜杠 `\`，必须写为 `\\`（如 `C:\\music_cache`），否则 JSON 解析会出错。

---

## 📋 字段详解

### 1. 必填项（缺失或为空时 API 禁用）

| 字段名      | 类型   | 说明                                                                                                                                 |
|-------------|--------|--------------------------------------------------------------------------------------------------------------------------------------|
| `cacheDir`  | 字符串 | 音频缓存文件的存储目录。**Windows 用户强烈建议使用绝对路径**（如 `C:/music_cache`）。Linux/macOS 可使用相对或绝对路径。**API 会自动创建该目录**（含父目录）。 |
| `serveUrl`  | 字符串 | 外部 HTTP 服务器提供音频文件的访问地址，**必须以 `/` 结尾**。例如 `http://example.com/music/` 或 `http://localhost:8090/`。               |

---

### 2. 可选顶层配置

| 字段名             | 类型    | 默认值  | 说明                                                                                                                            |
|--------------------|---------|---------|---------------------------------------------------------------------------------------------------------------------------------|
| `ffmpegPath`       | 字符串  | `"ffmpeg"` | ffmpeg 可执行文件的路径。若 ffmpeg 不在系统 PATH 中，请填写完整路径（如 `/usr/bin/ffmpeg` 或 `C:\ffmpeg\bin\ffmpeg.exe`）。       |
| `maxAudioLength`   | 整数    | `45`    | 允许播放的最大视频时长，**单位：分钟**。设为 `0` 表示不限制。若设为负数，自动回退到 `45`。                                      |
| `maxCacheSize`     | 整数    | `100`   | 缓存目录允许的最大总大小，**单位：MB**。设为 `0` 表示不限制。若设为负数，自动回退到 `100`。**该清理仅在插件启动时触发一次**。    |
| `quality`          | 整数    | `6`     | ffmpeg 转码时的 `-q:a` 参数，取值范围 `0` ~ `9`，数值越低音质越高（文件越大）。若缺失或超出范围，自动回退到 `6`，不影响 API 启用。 |

---

### 3. `advanced` 高级选项（可选）

| 字段名        | 类型    | 默认值                                                                                                     | 说明                                                                                                                    |
|---------------|---------|------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------|
| `maxRetry`    | 整数    | `3`                                                                                                        | 搜索请求失败时的最大重试次数。设为 `0` 或负数表示不重试（但建议至少保留 1）。                                            |
| `retryDelay`  | 整数    | `1500`                                                                                                     | 每次重试之间的等待时间，**单位：毫秒**。设为 `0` 或负数表示不等待（可能造成请求过密）。                                    |
| `userAgent`   | 字符串  | `"Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36"` | 请求 B站 API 时使用的 User-Agent 头。一般无需修改，但若遇到访问限制可尝试更换。                                              |

---

## ⚙️ 配置生效

- 修改 `bili.json` 后，执行 `/music reload` 或重启服务器，API 会重新加载配置。
- 若配置文件损坏（JSON 格式错误、缺失必填字段等），会自动备份原文件并生成新的默认配置，API 将禁用，直至正确配置。
- **缓存目录自动创建**：若 `cacheDir` 指向的目录不存在，API 会自动创建（含父目录）。Windows 用户使用绝对路径可避免工作目录不确定性。
- **缓存清理**：若 `maxCacheSize > 0`，则在插件加载时检查缓存目录总大小，若超过限制则删除 **所有缓存文件**（不删除子目录），并记录日志。

---

## 🚨 注意事项

1. **Windows 用户强烈建议使用绝对路径**，如 `C:/music_cache` 或 `D:\\cache`（JSON 中转义为 `D:\\\\cache`）。相对路径可能导致缓存文件出现在非预期位置。
2. **`serveUrl` 务必以 `/` 结尾**，否则生成的播放链接可能不完整。
3. **ffmpeg 可用性**：启动时会执行 `ffmpeg -version` 验证，若失败则 API 禁用。
4. `quality` 为非必填项，缺失或值非法时自动使用默认值 `6`，不会导致 API 禁用。
5. 若使用反向代理（如 Nginx），`serveUrl` 应填写代理后的外部访问地址。
